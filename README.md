# Abhinav Upadhyay — Portfolio & Digital Hub

> Official personal website and digital platform for **Abhinav Upadhyay**, 18-year-old entrepreneur & founder of **[Assurance Digital](https://assurancedigital.vercel.app)**.  
> Designed with the signature aesthetic, typography, and color tokens inspired by **[darshjain.com](https://darshjain.com)**, enhanced with a modern **Liquid Glassmorphism UI**.

---

## 🚀 Features

- **Liquid Glassmorphism UI**: Ambient animated gradient lighting, backdrop-blur (`16px`), and interactive 3D card tilt perspective.
- **Recommended AI Tools**: Curated developer stack featuring **Google Antigravity**, **Anthropic Claude**, **OpenAI ChatGPT**, and **ElevenLabs**.
- **Assurance Digital Ecosystem**: Direct integration with **Assurance Digital Agency** and **Assurance OS**.
- **Live Supabase Backend**: Integrated with Supabase cloud database (`inquiries` table) with Row Level Security.
- **Google Sheets Sync**: Direct zero-dependency lead collection via Google Apps Script.
- **Copyable AI Blueprints**: Click-to-copy system prompts for web architecture, multi-agent systems, and AI phone agents.
- **Full Responsive Architecture**: Clean desktop navigation and mobile drawer menu.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Pure CSS with Custom Design Tokens & Liquid Glassmorphism
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend**: [Supabase](https://supabase.com/) & [Google Sheets Apps Script](https://developers.google.com/apps-script)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/assurancedigital6398-cmd/abhinavleads.git
cd abhinavleads
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://wvfyhudkbhgytdewyiiq.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_yzqVQ-TWlaiUbksfvfFrNw_OjGr6ew6
VITE_GOOGLE_SHEET_URL=
```

### 4. Run Development Server
```bash
npm run dev
```

### 5. Build for Production
```bash
npm run build
```
